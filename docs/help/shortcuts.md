# Keyboard shortcuts

On Windows, use **Ctrl** where this page says **⌘**, and **Alt** for **⌥**. Single-letter keys work when the slide has the focus, not while you're typing in a field.

## Tools

| Key | Tool |
| --- | --- |
| V | Pan and select |
| P | Pin |
| R | Ruler |
| F | Freehand outline |
| C | Circle |
| B | Rectangle |
| Esc | Cancel what you're drawing, then back to Pan |

## Annotations

| Key | Action |
| --- | --- |
| ↵ | Rename the selected pin or shape (or finish typing a title) |
| Double-click | Rename |
| Delete or ⌫ | Delete the selection |
| ⌘Z | Undo |
| ⇧⌘Z or ⌘Y | Redo |
| ⌘E | Export the slide's annotations (.ndpa)… |

## Moving around

| Key | Action |
| --- | --- |
| Scroll / pinch | Zoom in and out at the pointer |
| Drag | Pan (with the Pan tool) |
| H or 0 | Whole slide |
| ⌘0 | Zoom to fit |
| ] or → | Next slide in the folder |
| [ or ← | Previous slide in the folder |
| ⇧ + arrow | Pan a quarter screen |
| + / − | Zoom in / out |
| , / . | Rotate the view 90° left / right |
| ⇧, / ⇧. | Rotate by the small step (15°) |
| Page Up / Page Down | Focal plane up / down (z-stacks) |
| Right-drag | Pan, with any tool |

## Window and files

| Key | Action |
| --- | --- |
| ⌘O | Open a folder of slides |
| ⌘R | Rescan the folder |
| ⇧⌘S or ⇧S | Save a snapshot (PNG) |
| \\ | Adjustments on / off (compare with the original) |
| ⌥⌘1 | Show or hide the slide browser |
| ⌥⌘2 | Show or hide the side panel |
| ⌘, | Preferences |
| ⇧⌘/ | Help |
| ⌘W | Close the window |

See [Rotate](viewing.md#rotate) and [Focal planes](viewing.md#focal-planes) for more on those keys.

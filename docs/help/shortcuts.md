# Keyboard shortcuts

On Windows, use **Ctrl** where this page says **⌘**, and **Alt** for **⌥**. Single-letter keys work when the slide has the focus, not while you're typing in a field. To make them work *only* while the slide has the focus, turn on **Preferences ▸ Accessibility ▸ Single-key shortcuts** (see [Accessibility](accessibility.md#accessibility-preferences)).

## Tools

| Key | Tool |
| --- | --- |
| V | Pan and select |
| P | Pin |
| R | Ruler |
| F | Freehand outline |
| C | Circle |
| B | Rectangle |
| Esc | Cancel what you're drawing, then back to Pan |

## Annotations

| Key | Action |
| --- | --- |
| ↵ or F2 | Rename the selected pin or shape (or finish typing a title) |
| Double-click | Rename |
| Delete or ⌫ | Delete the selection |
| ⌘Z | Undo |
| ⇧⌘Z or ⌘Y | Redo |
| ⌘E | Export the slide's annotations (.ndpa)… |
| N / ⇧N | Select the next / previous annotation and move the view to it |
| ⌥ + arrow | Move the selected annotations a little (⌥⇧ + arrow: further) |
| ⇧F10 or the Menu key | The menu of the selection (style, colour, rename, delete), or the slide menu |

## Keyboard cursor

The keyboard cursor is a cross-hair in the middle of the view. You move the slide under it with the arrow keys, then act on the spot under it, so you can place pins and draw shapes without a mouse. See [Keyboard only](accessibility.md#keyboard-only).

| Key | Action |
| --- | --- |
| X | Keyboard cursor on / off |
| ↵ (on the slide) | Keyboard cursor on |
| ← → ↑ ↓ | Pan a tenth of the view (while the keyboard cursor is on) |
| ⇧ + arrow | Pan a quarter of the view |
| Space | A click at the cursor: select what's under it, place a pin with the Pin tool, or set a point |
| ↵ | With the Pan tool: the slide menu at the cursor. With a drawing tool: set a point |
| P / ⇧P | Place a pin / a flag at the cursor and type its title |
| R, C or B, then Space twice | Ruler, circle (centre, then edge) or rectangle (corner to corner): pan between the two presses |
| F, then Space for each point | Freehand outline. ⇧↵, or Space back on the first point, closes it. ⌫ removes the last point |
| Esc | Cancel the drawing, then clear the selection, then back to Pan, then keyboard cursor off |
| Tab | Leave the slide (it never keeps the focus) |

## Menus

| Key | Action |
| --- | --- |
| ↑ ↓ | Move through the items |
| Home / End | First / last item |
| A letter | Jump to the next item starting with it |
| → , ↵ or Space | Open a submenu |
| ← or Esc | Close the submenu |
| ↵ or Space | Choose the item |
| Esc or Tab | Close the menu |

## Moving around

| Key | Action |
| --- | --- |
| Scroll / pinch | Zoom in and out at the pointer |
| Drag | Pan (with the Pan tool) |
| H or 0 | Whole slide |
| M | Show / hide the overview map |
| ⌘0 | Zoom to fit |
| ] | Next slide in the folder (also → while the keyboard cursor is off) |
| [ | Previous slide in the folder (also ← while the keyboard cursor is off) |
| ⇧ + arrow | Pan a quarter screen |
| + / − | Zoom in / out |
| , / . | Rotate the view 90° left / right |
| ⇧, / ⇧. | Rotate by the small step (15°) |
| Page Up / Page Down | Focal plane up / down (z-stacks) |
| T / ⇧T | Next / previous time point (time series) |
| Right-click | Menu: add a pin or flag, draw a shape, zoom, rotate |

## Window and files

| Key | Action |
| --- | --- |
| ⌘O | Open a folder of slides |
| ⇧⌘O | Open a single slide file |
| ⌘R | Rescan the folder |
| ⇧⌘S or ⇧S | Save a snapshot (PNG) |
| \\ | Adjustments on / off (compare with the original) |
| ⌥⌘1 | Show or hide the slide browser |
| ⌥⌘2 | Show or hide the side panel |
| ⌘, | Preferences |
| ⇧⌘/ | Help |
| ⌘W | Close the window |

See [Rotate](viewing.md#rotate) and [Focal planes](viewing.md#focal-planes) for more on those keys.

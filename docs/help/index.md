# Slide Viewer Help

Slide Viewer opens whole-slide images (NDPI, SVS, TIFF and more) so you can study histology slides,
adjust how they look, measure structures, and place named pins. Pins and shapes are saved as `.ndpa`
files next to each slide, the same format Hamamatsu NDP.view2 uses.
